# Tickets

Every build ticket from Plan section 16F.2. **This file is the only place ticket status is kept.** Claude defines the tickets in the Plan; whoever finishes one updates its row here, in the same commit.

Status values: `NOT STARTED`, `IN PROGRESS`, `PARTIAL`, `DONE`, `BLOCKED`. `PARTIAL` includes SQL that is written in `SQL/` but not applied to Supabase. For a Manus ticket, put the migration file names and the date applied in Notes, so OpenHands knows the contract is live. For any ticket, name the commit.

Ids: `M-` is Manus AI (Supabase, Cloudflare), `O-` is OpenHands (app code). Tickets for the Phase 2 modules not listed here (Hotels onward) and for Phases 3 to 5 are written by Claude when Phase 1 is complete. Migrations already in `SQL/` without a ticket (`…shop_subscriptions`, `…owner_ledger`, `…shop_templates`, `…template_events`) belong to Phase 3 and get tickets then.
